
# Lebanon Tourism Data Explorer

An interactive Streamlit dashboard exploring tourism patterns across Lebanese areas and towns.

## About the Project

This dashboard was developed for the Data Visualization and Communication course at the American University of Beirut.

The dashboard uses the Lebanon Tourism dataset and focuses on:

- Average Tourism Index across areas
- The relationship between the number of restaurants and Tourism Index

## Interactivity

The dashboard includes two linked interaction features:

1. Area selection
2. Town selection

The Town selection is dependent on the selected Area, allowing users to drill down from an area to specific towns.

## Tools Used

- Python
- Pandas
- Plotly
- Streamlit
